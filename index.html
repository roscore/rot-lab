    Conventions used by rot-lab

    • Active rotations, column vectors, right-handed frames: v′ = R v. 90° about +Z takes +X to +Y.
    • Hamilton quaternions (i² = j² = k² = ijk = −1). q = (w, x, y, z) with w = cos(θ/2). q·p means “apply p, then q”, matching R(q)R(p). (The JPL convention, used in some aerospace/VIO code, multiplies the other way.)
    • Quaternion order: wxyz (MuJoCo, Eigen constructor, Isaac Sim, scipy scalar_first=True) vs xyzw (ROS / tf2 / geometry_msgs, scipy default, PyBullet). Same numbers in the wrong order are a completely different rotation.
    • Intrinsic A-B-C: rotate about body A, then the new body B, then the newest C: R = RA(a) RB(b) RC(c).
    • Extrinsic A-B-C: rotate about world A, then world B, then world C: R = RC(c) RB(b) RA(a). Therefore extrinsic X-Y-Z (r, p, y) = intrinsic Z-Y-X (y, p, r).
    • URDF rpy = extrinsic X-Y-Z in radians. Aerospace yaw-pitch-roll = intrinsic Z-Y′-X″. MuJoCo eulerseq: lowercase letters = intrinsic (default “xyz”), uppercase = extrinsic.
    • Gimbal lock: when the middle angle is ±90° (Tait-Bryan) or 0°/180° (proper Euler), the first and third axes line up; only their sum or difference is defined. rot-lab then sets the third angle to 0 and the matrix is still exact.
    • Rotation vector = axis·angle (the so(3) logarithm), angle in [0, π]. 6D = first two columns of R, mapped back by Gram-Schmidt.
    • Privacy: all computation happens in your browser. The share link stores state in the URL fragment (#…), which browsers never send to a server.

    rot-lab에서 사용하는 규약

    • 능동(active) 회전, 열벡터, 오른손 좌표계: v′ = R v. +Z축으로 90° 회전하면 +X가 +Y로 갑니다.
    • Hamilton 쿼터니언 (i² = j² = k² = ijk = −1). q = (w, x, y, z), w = cos(θ/2). q·p는 “p를 먼저, 그다음 q”를 적용하며 R(q)R(p)와 같습니다. (일부 항공/VIO 코드의 JPL 규약은 곱셈 순서가 반대입니다.)
    • 쿼터니언 순서: wxyz (MuJoCo, Eigen 생성자, Isaac Sim, scipy scalar_first=True) vs xyzw (ROS / tf2 / geometry_msgs, scipy 기본값, PyBullet). 같은 숫자라도 순서가 틀리면 완전히 다른 회전입니다.
    • Intrinsic(내재) A-B-C: 몸체 A축, 그다음 새로운 몸체 B축, 그다음 C축 순으로 회전: R = RA(a) RB(b) RC(c).
    • Extrinsic(외재) A-B-C: 고정된 월드 A축, B축, C축 순으로 회전: R = RC(c) RB(b) RA(a). 따라서 extrinsic X-Y-Z (r, p, y) = intrinsic Z-Y-X (y, p, r).
    • URDF rpy = 라디안 단위 extrinsic X-Y-Z. 항공 yaw-pitch-roll = intrinsic Z-Y′-X″. MuJoCo eulerseq: 소문자 = intrinsic (기본 “xyz”), 대문자 = extrinsic.
    • 짐벌 락: 가운데 각이 ±90° (Tait-Bryan) 또는 0°/180° (proper Euler)이면 첫째 축과 셋째 축이 겹쳐 두 각의 합/차만 정의됩니다. 이때 rot-lab은 셋째 각을 0으로 두며, 행렬은 그대로 정확합니다.
    • 회전 벡터 = 축·각 (so(3) 로그), 각도 범위 [0, π]. 6D = R의 처음 두 열, Gram-Schmidt로 R 복원.
    • 개인정보: 모든 계산은 브라우저 안에서만 이뤄집니다. 공유 링크는 URL fragment(#…)에 상태를 담으며, 브라우저는 이를 서버로 보내지 않습니다.
